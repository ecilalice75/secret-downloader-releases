# Installation sous Windows

[**Télécharger la dernière version**](https://github.com/ecilalice75/secret-downloader-releases/releases/latest/download/SecretDownloader-setup.exe)

Windows peut afficher deux avertissements avant l'installation. Voici comment les franchir.

## 1. Conserver le téléchargement

Le navigateur peut bloquer le fichier `SecretDownloader-setup.exe` pendant son téléchargement.

- **Dans Microsoft Edge :** ouvrez le menu `⋯` du téléchargement, puis cliquez sur **Conserver**. Si une confirmation supplémentaire apparaît, choisissez **Afficher plus**, puis **Conserver quand même**.
- **Dans Google Chrome :** ouvrez les téléchargements avec la flèche, puis cliquez sur **Conserver**.
- **Dans Mozilla Firefox :** ouvrez le panneau des téléchargements, cliquez sur la flèche vers la droite à côté du fichier, puis sur **Autoriser le téléchargement**.

## 2. Autoriser le lancement

Ouvrez ensuite `SecretDownloader-setup.exe`.

Si Windows affiche **Windows a protégé votre PC**, cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**. Vous pouvez alors terminer l'installation.
